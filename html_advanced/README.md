# Advanced HTML

This directory contains my solutions for the Holberton School project
**"Advanced HTML"**.

The goal of this project is to learn how to build and structure web pages
using semantic HTML5 elements. It focuses on creating clean page skeletons
without CSS styling, while paying close attention to proper HTML structure
and document organization.

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- All files must end with a new line
- A `README.md` file at the root of this project directory is mandatory
- All HTML files must be W3C compliant unless a task says otherwise
- The project uses the company name **Techium** across all webpages
- HTML tags and attributes must be written carefully
- Case sensitivity matters

## Learning Objectives

- How to create the skeleton of an HTML5 page
- How to use semantic HTML tags to structure a web page
- The difference between `div` and `span`
- The semantic value of `header`, `main`, `footer`, `article`, `nav`,
  `section`, and `aside`
- How to use headings in the correct hierarchical order
- How to make lists in HTML
- How to structure data in a table
- How to integrate video, audio, and iframe content
- How to embed external content
- How to correctly structure an HTML page
